# Mafia Workbench

Projekt komplexního editoru pro původní Mafia: The City of Lost Heaven (2002), s cílem maximální modifikovatelnosti hry. Desktopová aplikace bude navržena pro Electron.

Editor zatím není implementovaný. Počáteční commit uchovává zadání a úplný seznam referencí; žádné herní soubory ani soukromé referenční snapshoty nejsou součástí repozitáře.

- [Zadání a požadavky](goal.json)
- [Všech 16 referenčních repozitářů](research/repositories.json)

Vývoj začne rozborem formátů a licencí, extrakcí lokálních DTA archivů a ověřením bezpečných úprav nad kopií dat. Cílem je editace scén, modelů, animací, misí a skriptů, tabulek, textur, zvuků a cutscén, včetně možnosti vrátit změny a otestovat je ve hře.
